# 📝 Task Management Mini Project

A full-stack **Task Management Web Application** designed to help users organize, manage, and track their daily tasks.

The project demonstrates practical experience with **Node.js, Express.js, EJS, JavaScript, and web application development**.

## 🚀 Live Demo

🌐 **Live Application:**
https://a2z47-task-7h16.onrender.com/

## ✨ Features

* 📝 Create and manage tasks
* 📋 View task information
* ✏️ Update task details
* 🗑️ Delete tasks
* 🌐 Dynamic web pages using EJS
* ⚡ Backend routing using Express.js
* 📱 User-friendly web interface
* ☁️ Deployed online using Render

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/jay3703/a2z47_task.git
```

### 2. Navigate to the project folder

```bash
cd a2z47_task
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file for sensitive configuration such as database credentials or secret keys.

Example:

```env
DATABASE_URL=your_database_url
```

Do not upload `.env` to GitHub.

### 5. Start the application

```bash
npm start
```

If your project uses nodemon:

```bash
npm run dev
```

### 6. Open in browser

```text
http://localhost:3000
```
